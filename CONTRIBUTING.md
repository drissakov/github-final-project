# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Report an issue

Check the existing [issues](https://github.com/drissakov/simple_calculator/issues) before opening a new one. For a bug report, include the steps to reproduce the problem, the expected result, the actual result, and your Bash version. Do not include passwords or other private information.

## Submit a change

1. Fork the repository and create a branch for your change.
2. Keep the change focused and update the documentation when behavior changes.
3. Run `bash -n simple-interest.sh` to check the script syntax, then run `bash simple-interest.sh` with representative inputs to verify the calculation.
4. Commit your changes with a clear message and open a pull request explaining the change and how you checked it.
